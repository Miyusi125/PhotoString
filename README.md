# Photo String · 나의 작은 사진 줄

좋아하는 사진을 끈과 집게에 걸어 Windows 바탕화면을 꾸미는 프로그램입니다. 사진을 자유롭게 옮기고, 메모를 붙이고, 끈과 양 끝의 노브 디자인을 바꿀 수 있습니다.

장식은 바탕화면에 표시되며, 다른 프로그램 창을 열면 그 뒤에 가려집니다. 편집을 잠그면 사진 위로 마우스 클릭이 통과해 바탕화면을 평소처럼 사용할 수 있습니다.

## 사용 환경

- Windows 10 / 11, 64비트(x64)
- .NET Framework 4.8 이상
- 사진과 설정을 저장할 수 있는 쓰기 권한이 있는 폴더

별도 설치 과정이나 인터넷 연결 없이 실행합니다. 관리자 권한은 필요하지 않습니다.

## 다운로드와 첫 실행

1. GitHub 프로젝트 페이지의 **Releases**에서 사용할 버전을 엽니다.
2. **Assets**에서 **PhotoString-Windows.zip**을 다운로드합니다. 실행용 파일은 이 ZIP에 들어 있습니다.
3. ZIP의 압축을 원하는 폴더에 완전히 풉니다.
4. 압축을 푼 폴더의 **PhotoString.exe**를 더블클릭합니다.

ZIP 안에서 실행하지 말고, 압축을 푼 뒤 실행하세요. `Source code`로 표시된 다운로드는 개발용 소스입니다.

처음 실행하면 두 개의 끈과 여섯 개의 샘플 그림이 표시됩니다. 실행 파일 옆에는 사진과 배치를 보관할 `data` 폴더가 자동으로 만들어집니다.

## 내 사진으로 꾸미기

1. 설정 화면의 **＋ 사진 추가**를 누르고 사진을 선택합니다. 여러 장을 한 번에 선택해도 됩니다.
2. 샘플 그림이 필요 없다면 **··· → 샘플 그림 모두 떼기**를 선택합니다.
3. 오른쪽 **화면** 목록에서 장식을 표시할 모니터를 고릅니다.
4. **배치 미리보기**에서 사진과 끈을 드래그해 배치합니다. 녹색 테두리 안쪽이 실제 모니터에 표시되는 영역입니다.
5. 오른쪽 아래 **적용 후 실행**을 누릅니다.
6. 설정 창이 닫히면 바탕화면에서 장식을 확인합니다. 다른 창이 가리고 있다면 `Win + D`를 눌러 바탕화면을 확인하세요.

**적용 후 실행**은 배치를 저장하고, 숨긴 장식도 다시 표시하며, 바탕화면에서의 편집을 잠급니다. 저장이나 바탕화면 연결에 실패하면 설정 창이 열린 채로 아래에 오류가 표시됩니다.

설정을 다시 바꾸려면 `Ctrl + Alt + P`를 누르거나 작업 표시줄의 Photo String 트레이 아이콘을 더블클릭하세요. 아이콘이 보이지 않으면 작업 표시줄의 숨겨진 아이콘 목록을 확인합니다.

## 사진 편집

사진을 클릭하면 설정 화면 아래에서 해당 사진을 편집할 수 있습니다.

| 하고 싶은 일 | 조작 방법 |
| --- | --- |
| 사진 추가 | **＋ 사진 추가**를 누르거나 사진 파일을 배치 미리보기에 끌어놓기 |
| 위치 이동 | 미리보기에서 사진을 드래그 |
| 사진 교체 | 사진을 더블클릭하거나 선택한 뒤 **교체** 클릭 |
| 크기 조절 | 사진 위에서 마우스 휠을 돌리거나 **사진 크기** 슬라이더 사용 |
| 기울기 조절 | 사진 위에서 `Shift + 마우스 휠`을 사용하거나 **기울기** 슬라이더 사용 |
| 메모 입력 | 사진을 선택하고 아래 **사진 메모** 입력란 수정 |
| 다른 끈으로 이동 | 사진을 우클릭하고 **다른 끈으로 옮기기**에서 대상 끈 선택 |
| 사진 제거 | 사진을 선택하고 **사진 떼기** 클릭 |

사진을 교체해도 집게 위치와 레이어 순서는 유지됩니다. 사진을 떼어도 원본 사진 파일은 삭제되지 않습니다.

메모에는 한글과 이모티콘을 입력할 수 있습니다. 긴 메모는 사진 너비에 맞춰 말줄임표로 표시됩니다. 이모티콘의 모양은 Windows에서 지원하는 글꼴에 따라 달라질 수 있습니다.

### 사진이 겹칠 때: 레이어 순서 바꾸기

1. 설정 화면 아래의 **사진 레이어** 목록에서 조절할 사진을 선택합니다. 다른 사진에 완전히 가려진 사진도 이 목록에서 선택할 수 있습니다.
2. **뒤로**, **앞으로**, **맨 뒤**, **맨 앞**으로 순서를 바꿉니다.

목록의 숫자가 클수록 앞에 표시됩니다. 집게와 그림자도 해당 사진과 함께 순서가 바뀝니다. 아래쪽 사진의 집게가 위쪽 사진을 가리면, 아래쪽 사진을 선택해 **뒤로** 또는 **맨 뒤**로 보내세요. 사진 우클릭 메뉴에서도 순서를 바꿀 수 있습니다.

## 끈 배치와 화면 영역

- **끈 추가**를 누르면 새 끈을 만들 수 있습니다.
- 끈을 드래그하면 그 끈에 매달린 사진들이 함께 움직입니다.
- 끈 양 끝의 **노브(고정핀)**를 드래그하면 끈의 길이와 양 끝의 높이를 바꿀 수 있습니다.
- 노브를 미리보기의 녹색 테두리 쪽으로 끌면 화면 끝에 붙일 수 있습니다.
- 설정 미리보기의 노브는 항상 사진보다 앞에 표시되어, 사진과 겹쳐 있어도 선택할 수 있습니다.

미리보기의 **녹색 테두리**는 선택한 모니터의 화면 전체에 해당합니다. 주변 여백은 배치 영역이 아닙니다. 테두리 아래에 표시되는 화면 크기로 적용할 모니터를 확인하세요.

장식 한 세트는 선택한 한 모니터에 표시됩니다. 모니터를 바꾸면 배치는 해당 화면 크기에 맞춰 표시됩니다.

**··· → 비어 있는 끈 정리**로 사진이 없는 끈을 제거할 수 있습니다. 사진은 최대 120장, 끈은 최대 8개까지 사용할 수 있습니다.

## 끈과 노브 디자인 꾸미기

설정 화면 오른쪽 위의 **끈 · 노브 꾸미기**를 누릅니다.

1. **적용 대상**에서 전체 끈 또는 원하는 끈 하나를 선택합니다.
2. **디자인 카탈로그**에서 기본 디자인을 고르거나, 원하는 항목을 직접 조절합니다.
3. 꾸미기를 마치면 **완료**를 누릅니다.

변경은 바로 반영되고 자동 저장됩니다. 처음 사용하는 경우에는 카탈로그의 기본 디자인 8종 중 하나를 골라 시작해 보세요.

| 대상 | 바꿀 수 있는 항목 |
| --- | --- |
| 끈 | 색상, 황마·면·나일론·가죽·금속 재질, 질감, 한 줄·두 줄 디자인, 두께 |
| 노브 | 색상, 나무·금속·플라스틱·돌·유리 재질, 질감, 원형·둥근 사각·육각형·꽃 모양·이미지 디자인, 크기 |

색상은 색 선택 버튼이나 `#RRGGBB` 형식의 색상 코드로 지정할 수 있습니다.

### 왼쪽과 오른쪽 노브를 따로 설정하기

노브는 끈 양 끝의 고정핀을 뜻합니다.

1. 노브 설정의 **적용 쪽**에서 **왼쪽 노브** 또는 **오른쪽 노브**를 선택합니다.
2. 색상·재질·질감·디자인·크기를 바꾸거나 이미지를 가져옵니다.
3. 반대쪽도 바꾸려면 **적용 쪽**을 변경한 뒤 다시 설정합니다.

처음에는 **왼쪽 노브**가 선택되어 있습니다. 선택한 쪽에만 변경 사항이 적용됩니다. **양쪽 노브**를 고르면 변경한 항목이 양쪽에 적용되며, 화면에는 왼쪽 노브의 값이 표시됩니다.

### 내 이미지로 질감과 노브 만들기

| 버튼 | 용도 |
| --- | --- |
| 끈의 **질감 이미지 가져오기** | JPG·PNG 등의 이미지를 끈에 반복해서 입히기 |
| 노브의 **질감 이미지** | 이미지를 선택한 노브 모양 안에 입히기 |
| 노브의 **노브 PNG** | 내 노브 이미지를 모양과 투명도를 유지해 표시하기 |
| **이미지 해제** | 가져온 이미지를 해제하기. 노브는 선택한 쪽에 적용 |

노브 자체의 모양을 바꾸려면 배경이 투명한 PNG를 사용하세요. 이미지 가져오기 전에 **적용 대상**과 노브의 **적용 쪽**을 확인하면 원하는 끈과 끝부분에만 적용할 수 있습니다.

### 내 디자인 저장하기

꾸미기 창 아래에 이름을 입력하고 **내 디자인 저장**을 누르면 현재 디자인이 개인 카탈로그에 추가됩니다. 나중에 카탈로그에서 다시 선택할 수 있습니다.

카탈로그 디자인을 선택하면 적용 대상 끈의 디자인과 양쪽 노브 설정이 함께 바뀝니다. **선택한 내 디자인 삭제**는 개인 카탈로그 항목을 지우며, 이미 배치에 적용한 디자인은 유지됩니다.

## 바탕화면에서 직접 편집하기

1. 설정 화면에서 **바탕화면에서 편집**을 누릅니다.
2. 바탕화면에 표시된 사진과 끈을 드래그해 조절합니다.
3. 설정 화면으로 돌아와 **편집 잠그기**를 누릅니다.

편집을 잠그면 장식 위의 클릭이 바탕화면으로 통과합니다. 설정 화면의 미리보기에서는 잠금 상태와 관계없이 편집할 수 있습니다. **적용 후 실행**을 눌러도 편집이 잠깁니다.

## 숨기기, 설정 창 다시 열기, 종료

| 하고 싶은 일 | 방법 |
| --- | --- |
| 장식 잠시 숨기기 | 설정 화면에서 **사진 숨기기** |
| 숨긴 장식 다시 표시 | 설정 화면에서 **사진 표시** 또는 **적용 후 실행** |
| 설정 창 닫기 | 설정 창의 닫기 버튼. 프로그램과 사진 장식은 계속 실행 |
| 설정 창 다시 열기 | `Ctrl + Alt + P` 또는 Photo String 트레이 아이콘 더블클릭 |
| 프로그램 완전히 종료 | 트레이 아이콘 우클릭 → **종료**, 또는 설정 화면 **··· → 프로그램 종료** |

Windows 로그인 시 자동 실행되지는 않습니다. 사용하려면 `PhotoString.exe`를 실행하세요.

## 저장과 백업

배치와 메모는 변경 후 자동 저장됩니다. 설정 화면 아래에 **배치 저장됨**이 표시되면 저장이 완료된 상태입니다.

실행 파일 옆의 `data` 폴더에 다음 내용이 보관됩니다.

| 위치 | 저장 내용 |
| --- | --- |
| `data/arrangement.json` | 사진 배치, 메모, 레이어와 끈 설정 |
| `data/photos/` | 추가한 사진의 복사본 |
| `data/materials/` | 가져온 질감과 노브 이미지 |
| `data/catalog.json` | 내 디자인 카탈로그 |

추가한 사진은 프로그램 폴더에 복사되므로 원본 사진을 다른 곳으로 옮겨도 장식은 유지됩니다. **백업하려면 프로그램을 종료하고 `data` 폴더 전체를 복사하세요.** 다른 위치나 PC로 옮길 때도 실행 파일과 `data` 폴더를 함께 옮깁니다.

**··· → 기본 배치로 되돌리기…**는 현재 배치를 샘플 배치로 바꿉니다. 기존 배치를 보관하려면 먼저 `data`를 백업하세요.

## 새 버전으로 업데이트하기

1. 트레이 메뉴의 **종료**로 프로그램을 완전히 종료합니다.
2. 현재 실행 파일 옆의 `data` 폴더를 백업합니다.
3. 새 버전의 `PhotoString-Windows.zip`을 다운로드하고 별도 위치에 압축을 풉니다.
4. 새 **PhotoString.exe**를 기존 프로그램 폴더에 복사해 교체합니다. 기존 `data` 폴더는 유지합니다.
5. 교체한 실행 파일을 열고 사진과 배치를 확인합니다.

새 폴더에서 실행하려면 기존 `data` 폴더도 새 실행 파일 옆으로 복사하세요. `data` 없이 실행하면 기본 샘플 배치로 시작합니다.

프로그램을 제거하려면 종료 후 압축을 풀었던 폴더를 삭제합니다. 사진과 배치를 남겨두고 싶다면 삭제 전에 `data`를 백업하세요.

## 자주 겪는 문제

### 바탕화면에 사진이 보이지 않아요

1. 설정 화면에서 **적용 후 실행**을 누릅니다.
2. `Win + D`로 바탕화면을 확인합니다.
3. 설정 화면의 **화면** 목록에서 선택한 모니터를 확인합니다.
4. 설정 창이 닫히지 않았다면 아래쪽의 오류 메시지를 확인합니다.
5. 계속 보이지 않으면 트레이에서 프로그램을 종료하고 다시 실행합니다.

Wallpaper Engine 같은 배경화면 프로그램을 함께 사용하는 경우에는 해당 프로그램을 잠시 종료한 상태와 비교해 보세요.

### 설정 창을 닫았는데 프로그램이 계속 실행돼요

설정 창을 닫으면 트레이로 숨겨집니다. 장식까지 종료하려면 트레이 아이콘을 우클릭하고 **종료**를 선택하세요.

### 단축키로 설정 창이 열리지 않아요

다른 프로그램이 같은 단축키를 사용하면 등록되지 않을 수 있습니다. 작업 표시줄의 숨겨진 아이콘 목록에서 Photo String 아이콘을 찾아 더블클릭하세요.

### 사진이 가려져 선택할 수 없어요

설정 화면 아래 **사진 레이어** 목록에서 사진을 선택한 뒤 **앞으로** 또는 **맨 앞**으로 이동하세요.

### 사진 파일을 불러올 수 없어요

지원 형식은 JPG/JPEG, PNG, BMP, GIF, TIFF입니다. GIF는 정지된 첫 프레임으로 표시됩니다. HEIC와 WebP는 기본 지원 형식에 포함되지 않으므로 JPG 또는 PNG로 변환해 가져오세요.

### 저장에 실패하거나 다시 실행하면 배치가 사라져요

설정 화면 아래의 저장 오류를 확인하세요. ZIP 안에서 실행했다면 압축을 완전히 풀고 실행합니다. 프로그램 폴더에 쓰기 권한이 없다면 쓰기 가능한 위치로 실행 파일과 `data`를 함께 옮깁니다.

새 폴더에서 기본 샘플만 표시된다면 기존 `data` 폴더가 현재 실행 파일 옆에 있는지 확인하세요.
