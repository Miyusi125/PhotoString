# Photo String · 나의 작은 사진 줄

끈과 나무 집게에 사진을 걸어 Windows 바탕화면을 꾸미는 개인용 프로그램입니다. 다른 프로그램을 열면 장식은 그 뒤에 가려집니다. 별도 설치와 인터넷 연결은 필요하지 않습니다.

## 실행

배포 ZIP의 압축을 풀고 실행하세요. ZIP 안에서 바로 실행하지 마세요. data 폴더는 실행 파일 옆에 자동으로 만들어집니다.

`PhotoString.exe`를 더블클릭하세요. Windows 10/11 x64와 .NET Framework 4.8 이상이 필요합니다. 처음에는 두 개의 끈에 여섯 개의 샘플 그림이 걸립니다.

설정 화면에서 사진 배치를 정한 뒤 오른쪽 아래 **적용 후 실행**을 누르세요. 현재 배치를 바로 저장하고, 사진 장식을 표시하며, 바탕화면 편집을 잠근 뒤 설정 창을 닫습니다. 숨겨두었던 장식도 다시 표시됩니다. 다른 창이 바탕화면을 가리고 있다면 `Win+D`로 바탕화면을 확인하세요. 설정을 다시 변경하려면 `Ctrl+Alt+P`를 누릅니다.

## 사용 방법

- **사진 추가**: JPG, PNG, BMP, GIF, TIFF 파일을 선택합니다. 여러 장을 한 번에 추가하거나 관리창의 미리보기에 파일을 끌어놓을 수 있습니다. GIF는 정지된 첫 프레임으로 표시됩니다.
- **적용 후 실행**: 배치를 저장하고 바탕화면에 표시한 뒤 설정 창을 닫습니다. 저장이나 바탕화면 연결이 실패하면 설정 창을 유지하고 아래에 원인을 표시합니다.
- **사진 교체**: 미리보기에서 사진을 더블클릭하거나 선택 후 `교체`를 누릅니다. 집게 위치는 유지됩니다.
- **사진 레이어**: 설정 화면 아래 `사진 레이어` 목록에서 사진을 선택하고 `뒤로`, `앞으로`, `맨 뒤`, `맨 앞`으로 겹치는 순서를 바꿉니다. 숫자가 클수록 앞에 표시됩니다. 완전히 가려진 사진도 목록에서 선택할 수 있으며, 집게와 그림자는 사진과 함께 이동합니다. 사진 우클릭 메뉴에서도 순서를 바꿀 수 있습니다. 레이어 순서는 저장되며 사진을 교체해도 유지됩니다.
- **끈·노브 꾸미기**: 설정 화면 오른쪽 위의 `끈 · 노브 꾸미기`를 누릅니다. 전체 끈 또는 개별 끈을 선택한 뒤 색상, 재질, 질감, 디자인을 바꿉니다. 색 선택 창과 `#RRGGBB` 코드 입력을 지원하고, 끈 두께와 노브 크기도 조절할 수 있습니다. 변경은 바로 적용되고 자동 저장됩니다.
- **배치 이동**: 사진을 드래그합니다. 가로·세로 위치에 맞게 끈이 이어집니다. 끈을 드래그하면 매달린 사진들이 함께 움직이고, 양 끝의 원형 고정핀을 드래그하면 끈의 길이와 높이를 바꿀 수 있습니다.
- **설정 화면 조절 노브**: 설정 미리보기에서는 끈 양 끝의 원형 조절 노브가 항상 사진보다 앞에 표시되고 먼저 선택됩니다. 사진과 겹쳐 있어도 노브를 드래그해 끈의 길이와 높이를 바꿀 수 있습니다.
- **화면 끝에 붙이기**: 배치 범위는 선택한 모니터의 화면 전체입니다. 끈 양 끝의 고정핀을 가장자리 가까이 끌면 화면 끝에 붙습니다.
- **적용 영역 확인**: 배치 미리보기 안의 녹색 테두리가 실제 화면의 경계입니다. 선택한 모니터의 가로·세로 비율과 해상도를 표시하며, 테두리 안의 배치가 바탕화면에 적용됩니다.
- **크기·기울기**: 사진 위에서 휠을 돌려 크기를 조절합니다. `Shift+휠`로 회전합니다. 사진을 선택한 뒤 아래 슬라이더를 사용해도 됩니다.
- **메모·삭제**: 선택한 사진의 아래 입력란에서 메모를 바꿀 수 있습니다. 사진 메모에서는 Windows 이모티콘 글꼴의 색상 레이어를 표시하며, 긴 메모는 사진 너비에 맞춰 말줄임표로 표시합니다. 입력·저장 제한과 말줄임에서도 이모티콘과 조합 문자를 중간에 자르지 않습니다. `사진 떼기`, 우클릭 메뉴 또는 `Delete` 키로 배치에서 제거합니다. 원본 파일은 삭제하지 않습니다.
- **다른 끈으로 이동**: 사진을 우클릭한 뒤 원하는 끈을 선택합니다.
- **바탕화면에서 직접 편집**: `바탕화면에서 편집`을 누릅니다. 편집을 마치면 `편집 잠그기`를 누르세요. 잠긴 장식 위로는 클릭이 통과하므로 바탕화면을 평소대로 쓸 수 있습니다. 관리창 미리보기에서는 항상 편집할 수 있습니다.
- **모니터 선택**: 관리창 오른쪽의 화면 목록에서 장식을 표시할 모니터를 선택합니다. 장식 한 세트를 선택한 한 모니터에 표시합니다.
- **관리창 닫기**: 창을 닫아도 장식은 유지됩니다. 작업 표시줄의 숨겨진 아이콘에서 Photo String을 더블클릭하거나 `Ctrl+Alt+P`로 다시 엽니다.
- **종료**: 트레이 아이콘을 우클릭하고 `종료`를 선택합니다. 관리창 `···` 메뉴에서도 종료할 수 있습니다.

`···` 메뉴에서 샘플 그림 제거, 빈 끈 정리, 기본 배치 복원을 할 수 있습니다. 사진은 최대 120장, 새 끈은 최대 8개까지 지원합니다. 장식의 크기와 위치는 선택한 화면 크기에 비례합니다.

## 디자인 카탈로그와 이미지

내추럴 황마, 아이보리 코튼, 파스텔 핑크, 브라운 가죽, 실버 메탈, 블랙 미니멀, 숲과 돌, 맑은 유리의 기본 디자인 8종을 제공합니다. 모두 프로그램에서 직접 그리는 디자인이라 다운로드 없이 사용할 수 있습니다. 선택한 디자인을 수정한 뒤 이름을 입력하고 `내 디자인 저장`을 누르면 개인 카탈로그에 추가됩니다.

- 끈: 황마·면·나일론·가죽·금속 재질, 매끈·섬유 결·땋은 무늬·이미지 질감, 한 줄·두 줄 디자인. 이전에 저장된 점선은 한 줄로 표시됩니다.
- 노브: 나무·금속·플라스틱·돌·유리 재질, 나뭇결·브러시 결·돌 무늬·이미지 질감, 원형·둥근 사각·육각형·꽃·내 이미지 디자인.
- `질감 이미지 가져오기` 또는 노브의 `질감 이미지`로 JPG/PNG 등의 색상 이미지를 가져옵니다. 끈에는 반복해서, 노브에는 선택한 모양 안에 입힙니다.
- `노브 PNG`로 개인이 만든 노브 디자인을 가져올 수 있습니다. 투명 PNG를 사용하면 배경의 투명도와 그림의 모양이 유지됩니다.
- 노브의 `적용 쪽`에서 `왼쪽 노브` 또는 `오른쪽 노브`를 고른 뒤 이미지를 가져오세요. 이미지 가져오기·해제, 색상·재질·질감·디자인·크기는 선택한 쪽에만 적용됩니다. 처음에는 왼쪽이 선택됩니다. 함께 바꾸려면 `양쪽 노브`를 선택하세요. 양쪽의 설정이 다르면 왼쪽 값을 표시하며, 변경한 항목만 양쪽에 적용합니다. 좌우 설정은 배치와 내 디자인에 함께 저장됩니다. 카탈로그 디자인을 선택하면 끈 전체의 디자인과 좌우 노브 설정이 교체됩니다.

추가 질감은 [ambientCG](https://ambientcg.com/)나 [Poly Haven](https://polyhaven.com/textures)에서 Wood, Fabric, Metal 등을 찾아 구할 수 있습니다. 두 사이트는 다운로드하는 에셋에 CC0를 적용합니다. [ambientCG 라이선스](https://docs.ambientcg.com/license/), [Poly Haven 라이선스](https://polyhaven.com/license). 이 앱에 가져올 파일은 색상용 이미지인 **BaseColor / Albedo / Diffuse의 JPG·PNG**입니다. 1K 정도의 이미지면 충분하며 재질 선택은 2D 장식의 빛과 표면 표현을 바꿉니다.

## 저장

변경 사항은 자동으로 `data/arrangement.json`에 저장됩니다. 추가한 사진은 `data/photos/`에 복사되므로 원본 파일을 옮겨도 유지됩니다. 이전 저장본은 `.bak` 파일에 남습니다. 프로그램을 옮길 때는 실행 파일과 `data` 폴더를 함께 옮기세요. 쓰기 권한이 있는 폴더에서 실행해야 합니다.

꾸미기에 가져온 이미지는 `data/materials/`, 내 디자인 목록은 `data/catalog.json`에 저장됩니다. 기존 사진 배치에는 기본 디자인이 자동으로 연결됩니다. 카탈로그에서 내 디자인을 삭제해도 이미 적용된 디자인과 이미지 파일은 보관됩니다.

자동 시작 등록, 배경화면 교체, 사진 업로드는 하지 않습니다. 일반 사용자 권한으로 실행하며 관리자 권한으로 실행할 필요가 없습니다. HEIC/WebP는 이 버전의 기본 지원 형식에 포함되지 않습니다.
